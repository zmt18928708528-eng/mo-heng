# 墨衡

三列看板：待办、进行中、已完成。支持拖拽卡片、编辑标题与描述，进度保存在浏览器本地。

右上角可以导出 JSON 备份，也可从 JSON 导入。导入时可选择「合并」或「覆盖」当前看板。

## 本地运行

```bash
npm install
npm run dev
```

## 构建

```bash
npm run build
```

## 备份与拖拽

- 支持标准 JSON 备份、旧版卡片数组和本地存储导出；空看板也可备份和恢复。
- 导入会移除列内与跨列的重复引用，并将未分配的卡片放入待办。
- 合并时同 ID 的内容使用导入版本，已有卡片的位置优先保留。
- 跨列拖拽过程中按 Esc 或在没有落点时松开，会恢复拖拽前的位置。
- 日历按日期缓存卡片索引，避免为每个日期重复遍历整个看板。

## 验证

```bash
npm run typecheck
npm run test:kanban
npm run build
```

完整 `npm test` 还包含原始 Grok 模板测试；当前仓库缺少部分模板资源，且部分品牌期望与墨衡不符，因此这些测试存在既有失败。看板回归测试可通过 `npm run test:kanban` 独立运行。
